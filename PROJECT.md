# PROJECT.md

## Overview

**Cards** is an innovative AI-powered trading card game where every card is uniquely generated with AI-created artwork and dynamically determined attributes. Unlike traditional TCGs with fixed card sets, Cards creates a personalized experience where each player's collection is truly one-of-a-kind, combining procedural generation with OpenAI's cutting-edge image and language models.

## Purpose

This project explores the intersection of AI creativity and game design by creating a trading card game ecosystem where:
- Cards are generated from rich biome data (climate, wildlife, plants, elements)
- Artwork is created via DALL-E-3 based on descriptive prompts
- Game attributes (attack, defense, actions, flavor text) are determined by GPT-4
- Every card is unique to each user, ensuring no two collections are identical

The system demonstrates how AI can be used not just for automation, but for generative content creation in gaming.

## Architecture

### Service-Oriented Design

The backend follows a clean service-based architecture with four primary services:

1. **CardService** (`pkg/card/`) - Card lifecycle management
   - Generate cards from biomes or custom prompts
   - CRUD operations for cards
   - Deck management
   - Card template creation
   - Integration with AI service for image and attribute generation

2. **BiomeService** (`pkg/biome/`) - Biome data management
   - Store and retrieve biome characteristics
   - Parse biome JSON definitions
   - Generate biome-specific card templates
   - Manage wildlife, plants, elements, and resources per biome

3. **UserService** (`pkg/user/`) - Authentication and user management
   - User registration and login
   - JWT token generation
   - User profile management
   - Password security

4. **StoryService** (`pkg/story/`) - Narrative context (experimental)
   - Story generation and management
   - Contextual narratives for gameplay

### AI Service Layer

**AIService** (`pkg/ai/`) provides a unified interface to OpenAI APIs:
- **Image Generation**: DALL-E-3 integration for card artwork
- **Attribute Generation**: GPT-4 queries to determine card stats
- **Biome Extension**: AI-powered biome generation
- **Image Storage**: Downloads and stores generated images locally

### API Layer

Connect-RPC provides type-safe, protocol-buffer-based communication:
- HTTP/2 transport with backward compatibility (h2c)
- Automatic TypeScript/JavaScript client generation
- gRPC reflection for development tools
- CORS middleware for local development

### Database Layer

MySQL database with structured tables for:
- Users and authentication
- Cards with full metadata
- Biomes and characteristics
- Decks and card collections

## Major Components

### Card Generation Pipeline

The card generation system follows a sophisticated multi-stage pipeline:

```
Biome Selection → Element/Organism Selection → Description Template →
DALL-E-3 Image Generation → GPT-4 Attribute Generation → Card Persistence
```

**Card Types:**
- **Animal Cards**: Combine biome wildlife with elements
- **Plant Cards**: Combine biome vegetation with elements
- **Resource Cards**: Combine biome resources with elements

**Card Attributes:**
- `name`: Generated from element-organism combination
- `type`: Determined by AI (e.g., Creature, Enchantment)
- `element`: Selected from biome characteristics
- `attack`/`defense`: AI-generated stats
- `action`: Special ability text generated by GPT-4
- `mod`: Modifier effects
- `flavor`: Atmospheric flavor text
- `img_url`: Path to unique DALL-E-3 generated artwork

### Biome System

Biomes are JSON-defined environments with rich characteristics:
- **Climate** and **Vegetation** patterns
- **Wildlife** lists (animals that can appear on cards)
- **Plants** lists (flora that can appear on cards)
- **Elements** (fire, water, earth, etc.)
- **Element Descriptions** (visual contexts for card backgrounds)
- **Resources** (materials and items from the biome)
- **Resource Descriptions** (contextual details)

Biomes are stored in `pkg/biome/biomes/` and can be dynamically extended using AI.

## Unique Features

### 1. AI-Driven Card Generation
Every card is generated on-demand with unique artwork from DALL-E-3, ensuring visual variety impossible in traditional card games.

### 2. Procedural Attribute System
GPT-4 analyzes the card concept (biome + element + organism) and generates balanced, thematic attributes including attack values, defense stats, special actions, and flavor text.

### 3. Biome-Based Ecology
Cards aren't random—they emerge from coherent biome systems with wildlife, climate, and elemental themes that create natural synergies and deck-building strategies.

### 4. Element Fusion System
The core mechanic combines elements (fire, water, shadow, etc.) with organisms (animals/plants) to create hybrid cards like "Fire-Wolf" or "Water-Lotus", each with thematically appropriate abilities.

### 5. Dynamic Content Creation
Unlike static card databases, the system can generate new biomes via AI, extend existing ones, and create cards from custom prompts, making the game infinitely expandable.

### 6. User-Unique Collections
Each user's cards are generated specifically for them and stored with user ownership, creating true scarcity and uniqueness in digital card ownership.

### 7. Template System
Advanced users can create custom card generation templates, defining the rules and patterns for how cards are created from biome data.

## API Overview

### Card Service RPCs
- `GetCards` - Retrieve user's card collection
- `GetCard` - Get single card by ID
- `GenerateCards` - Generate N cards from a biome
- `CreateCard` - Create card with custom prompt
- `DeleteCard` - Remove card from collection
- `CreateCardTemplate` - Define custom generation template
- `GetDecks` - Retrieve user's decks
- `GetDeck` - Get specific deck by name

### Biome Service RPCs
- `CreateBiome` - Add new biome definition
- `GetBiome` - Retrieve biome by name
- `GetBiomes` - List all available biomes
- `GenerateBiomeCard` - Generate card from biome data

### User Service RPCs
- `CreateUser` - Register new user
- `Login` - Authenticate and receive JWT
- `GetUser` - Retrieve user profile
- `UpdateUser` - Modify user data
- `DeleteUser` - Remove user account
